# PDF 便條改為註解討論

Owner：專案維護者。授權：2026-10-05 使用者要求修正「新增便條」，使互動類似 Microsoft Office 註解，並修正點擊後跳到第一頁。風險：Low，本地可復原原型。

點「新增便條」後，在當前頁點選錨點，右側開啟尚未發布的註解卡片；輸入內容並發布才寫入 PDF。可選取既有便條、回覆、編輯或刪除自己的留言、解決／重新開啟、刪除討論。註解清單可跳到所屬頁面。發布、選取及重開註解不得意外回到第一頁；原 PDF 不被覆寫。

產品假設：這是單機離線討論，不含帳號、共同編輯、@提及或通知；新留言作者顯示「我」。在 PDF 中以標準文字註解保存首則內容；回覆與狀態使用 LocalPDF 私有中繼資料，其他閱讀器未必顯示討論串。

驗收：多頁合成 PDF 的第 2／3 頁建立、選取及更新註解後仍停留原頁；發布前不改 PDF；發布後可回覆、解決、編輯、刪除、復原、重做、另存及重開；舊式文字便條可在清單中檢視。
