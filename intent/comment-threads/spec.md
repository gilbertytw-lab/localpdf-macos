# 規格

- 註解錨點是頁面座標中的 24 pt PDF Text annotation。根留言放在標準 `/Contents`，供一般 PDF 閱讀器讀取。
- `/LocalPDFCommentThread` 存 JSON 版本、穩定 ID、根留言時間、回覆陣列及解決狀態。編輯根留言同時更新 `/Contents`。舊式 Text annotation 沒有中繼資料時，讀取為單則留言，第一次變更時升級。
- 點頁面建立草稿不寫入文件；空白不能發布。新增、編輯、回覆、解決、刪除各是一個復原步驟；所有變更沿用 workspace 的權限、快照及新檔儲存限制。
- 側欄呈現目前頁面與其他頁面註解，選取時移到其錨點。已解決註解仍可查閱及重新開啟。
- 文件重新渲染時恢復 controller 的目前頁面；避免程式性切頁通知將它覆蓋為 0。工具點擊既有註解錨點須先選取註解，不再重複新增。
