# 規格

來源：[intent.md](intent.md)。agent 擬稿；沿用本地原型風險政策。

- 新增文字模式點頁面空白處立即顯示空白文字框與輸入游標；使用原生 NSTextView 支援選字、換行、貼上及輸入法。點已有 LocalPDF 文字框可繼續編輯。
- 文字工具提供本機字體、6–144 pt 大小、顏色、粗體、斜體、底線與段落對齊。選取文字時套用選區；無選區時套用整框並更新後續輸入格式。字體無特定字重／斜體時使用原生合成屬性。
- 上方把手拖曳位置，右下角把手調整範圍；頁面座標限制在 CropBox 內，包含旋轉頁與非零原點。框過小或文字超出範圍時擴高至頁面允許高度；仍超出時拒絕完成並保留草稿，避免悄悄截斷。
- 編輯為草稿 session；完成、點框外、切換工具／頁面、其他文件操作與另存前提交一次快照。空的新框不保存；取消恢復編輯前狀態。session 中 Cmd-Z 使用原生文字復原，完成後使用文件復原。未儲存提示包含草稿。
- 保存為帶標準 PDF appearance stream 的 FreeText 註解，供其他 PDF 閱讀器顯示。RTF 與 UUID 自訂鍵（`/LocalPDFRTF`、`/LocalPDFID`）保存 LocalPDF 再編輯資料；不以可執行 archive 存儲。重新開啟、undo/redo 從資料還原富文字。原有 PDF 內容編輯限制維持。
- 原始輸入不寫回；有界歷史、權限與輸出驗證沿用。無網路、遠端字體或新執行期依賴；沿用本機 ad-hoc 開發打包。

驗收：新增／編輯混合格式和繁中、拖動與調整大小、重開繼續編輯、復原重做、另存前提交、空框／取消／無效範圍、Poppler 外觀交叉檢查及原生 UI 場景。
