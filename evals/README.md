# 代表性驗收

| 情境 | Fixture／操作 | 預期與證據 |
|---|---|---|
| 閱讀 | 3 頁文字 PDF | 原文可搜尋、頁數一致 |
| 頁面順序 | 標記 A／B／C 的文件 | 移頁、合併、抽取後文字順序一致 |
| 保存與復原 | rotate + 新增文字／圖片／highlight | 重開後外觀與內容存在；undo／redo 及 dirty 正確 |
| 保護原檔 | 原路徑、symlink、hardlink、合併來源 | 輸出被拒絕且輸入 byte 不變 |
| 失敗處理 | 無效 PDF、空頁選取、最後一頁刪除、不可寫路徑 | 可解釋的錯誤，workspace 不變 |
| 特殊權限 | 加密文件、widget 文件 | 不進入未驗證編輯路徑 |
| 展示隔離 | 對顯示副本修改 annotation 與頁面 | workspace 與輸出不被改變；輸出不帶新增的唯讀 flags |
| 容量邊界 | edit 前／後超過 snapshot 容量 | 不改動文件或立即回復，不留下無法 undo 的狀態 |
| 畫面驗收 | welcome 與有文件 + tools | 截圖可見真實 PDF、工具與狀態列；無重疊／裁切 |
| 原文修改 | 原字型重用字元／Helvetica 新英文 | 保存後新文可抽取、原文不再呈現，其他頁與註解保留 |
| 共用原圖 | 同一 Im1 多處繪製 | 只替換選取的出現位置；刪除可復原，其他頁保留 |
| 複雜內容 | clip、Form、無字型字元、過期 token | 明確拒絕，revision／dirty／undo 不變 |
| 色彩回歸 | CoreGraphics ICC 白底與綠色 path | 內容重建後白底、近似綠色保留，RGB 轉換明示 |
| 圖片外觀 | 上藍下綠、半邊透明 | 方向、透明度與原始顯示矩陣保存後保持 |
| 富文字框 | 原生輸入繁中、多行，選區粗斜體／底線／字體／顏色／對齊 | 保存重開保持 RTF、UUID 與標準 appearance，混合格式不影響其他文字 |
| 文字框座標 | 拖曳、調整尺寸，旋轉 0／90／180／270 與非零 CropBox | 位置在頁面範圍內；螢幕與頁面座標一致，undo／redo 保持識別 |
| 文字草稿 | 空框、取消、未按完成直接另存、過長文字 | 空框不保存，取消還原，另存提交，溢位保留草稿並提示 |
| 頁面管理 | 全頁網格、⌘／Shift 多選、批次旋轉／刪除／抽取、拖曳單頁及多頁 | 拖曳時縮小預覽跟隨游標，多頁紅字頁數在游標右上方；放下後消失，次序與選取正確；移動保持選中頁相對順序；undo／redo、另存與原檔保護正常 |
| 頁面內原文編輯 | 點原文、輸入、Enter、點空白處、Esc、錯誤字元、旋轉與縮放 | 編輯欄在文字原位置；成功改寫後可復原，錯誤保留草稿，取消不修改 PDF |
| 多頁舊便條 | 第 3 頁載入舊式 Text 註解、回覆、解決、另存重開 | 頁面保持第 3 頁；首則留言標準可讀，討論資料重開、復原／重做保留 |
| 舊便條 | 無討論中繼資料的 Text 註解 | 清單可見，回覆後升級為討論串 |
| 選字註解 | 第 3 頁選取一行與多行文字，點新增註解，Enter／點外確認 | 紅底及 45 度指標連浮動框；確認後框隱藏，hover 文字顯示，移出隱藏；另存重開紅底與內容保留 |
| 無效選區 | 未選字、跨頁選字、空白草稿 | 顯示提示或取消草稿，原檔及 workspace 不變 |
| 未選取版面 | 另一段文字含 6 pt tracking | 候選引擎輸出造成字距變化時拒絕整次修改，原 workspace 不變 |

自動案例使用 CoreGraphics、PDFKit 與自行產生的標準 PDF stream 合成 fixture，命令 `make test`；UI fixture 以 `make ui-check` 生成截圖。真實資料 corpus 尚未收集，結果不可外推為全部 PDF 相容性。後續問題必須新增對應 regression case。
