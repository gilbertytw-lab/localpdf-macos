# Specification

- 在「編輯原有內容」模式點擊頁面原有文字或從物件清單選取時，於該物件位置顯示並聚焦單行編輯欄；右側不再顯示獨立文字輸入框。
- 編輯欄保留原文字。Enter 或點擊頁面其他位置嘗試套用，Escape 取消。未修改就離開不建立復原紀錄。套用失敗時保留輸入及焦點供修正，並顯示現有內容引擎的錯誤。
- 工具切換、換頁、另存與其他文件操作先完成尚未套用的原文字修改；驗證失敗時中止該操作。選取另一物件時同樣先完成前一筆。
- 文字仍由 PDFium 改寫原 PDF 文字物件；原位置、字型大小與顏色依既有引擎保持。原字型僅支援已有字元，Helvetica 支援 Latin 基本文字；不提供多行重排。右側保留字型選擇、限制、刪除、圖片替換與物件清單。
- 編輯浮層只存在顯示副本，不輸出到 PDF；原檔唯讀，所有成功修改可復原。

驗收：原生頁面點字即可輸入；Enter、點外、Escape 與錯誤狀態正常；旋轉與縮放下欄位仍對齊；輸出 PDF 文字確實改變且可復原、原檔不變。
