# 規格

- 工具按鈕名改為「新增註解」，按下時讀取 PDFView 的文字選區。無文字或跨頁選區拒絕，不建立空白註解。
- 同頁多行選區保存每行頁面座標的矩形。新註解使用標準 PDF Highlight annotation，紅色半透明背景和 `/Contents` 首則註解內容；既有 `/LocalPDFCommentThread` JSON 延續 ID、回覆和解決狀態，新增錨點矩形供精準 hover 命中。
- 建立時使用只在顯示副本上的暫時紅底與浮動編輯框，確認才進 workspace 快照；空白確認取消。Enter 及框外點擊都走同一提交流程。
- 本機浮動框帶從文字錨點到框角的 45 度線；視窗邊緣可向左或向下翻轉以留在畫面內。確認後框隱藏；游標在註解文字範圍內顯示，離開即隱藏。一般 Text 便條繼續沿用舊資料閱讀方式。
- PDF 重新載入、縮放、捲動、旋轉後依頁面座標重算浮動框位置。所有正式變更可復原且不能覆寫來源。
