# Specification

- 主編輯器提供明確的「頁面管理」入口。進入後隱藏 PDF 編輯畫布與右側工具，展示依順序排列的全頁縮圖、頁碼、選取狀態與返回編輯入口。
- 點擊選單頁；⌘ 點擊切換多選，Shift 點擊選連續範圍；全選與取消選取可直接使用。操作列提供批次順時針旋轉、抽取 PDF 副本、刪除頁面。
- 拖曳單頁或已選頁面到另一頁：往後拖時置於目標頁後，往前拖時置於目標頁前；不可放在選取群組自身。多頁移動在一次可復原的 mutation 中完成，保持選取頁的原始順序。
- 開始拖曳後顯示比網格縮圖小的頁面預覽，位置隨游標即時更新，不攔截目標頁的命中測試。多頁時以紅字在游標右上方顯示「N 頁」；放下或取消時預覽與數字立即消失。單頁不顯示數字。
- 刪除前確認頁數與可復原性；禁止刪除最後一頁。抽取只輸出選中頁且不改變工作文件。工具／切頁前的編輯草稿在進入頁面管理前先完成，失敗時留在編輯器。
- 操作沿用 PDFWorkspace 的來源檔唯讀、快照與另存副本規則。返回編輯器後顯示目前排序及頁面。

驗收：實際多選、拖放排序、批次旋轉／刪除／抽取、undo／redo、保存重開、原檔不變；截圖確認完整頁面網格與選取、拖曳預覽／多頁紅色頁數及放下後消失。
